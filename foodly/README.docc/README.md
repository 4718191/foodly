

# 유통기한 관리 (foodly)
- 집에 있는 음식의 유통기한을 관리하는 iOS 앱입니다. SwiftUI와 SwiftData로 제작되었습니다.

## 주요 기능
### 📋 음식 관리
- 음식 이름, 유통기한, 보관 방법(냉장/냉동/실온)을 등록
- 음식 사진 첨부 (사진 라이브러리에서 선택)
- 바코드 스캔으로 상품명 자동 입력(카메라 + 공공데이터포털 API 연동)
- 항목 수정 및 삭제 (스와이프로 삭제)
- 모든 데이터는 앱을 껐다 켜도 유지됨 (SwiftData 로컬 저장)
### 🎨 목록 화면
- 유통기한이 임박한 순서로 자동 정렬
- 유통기한 상태에 따라 색상으로 구분
  - 🔴 빨강: 유통기한 지남
  - 🟠 주황: 3일 이내 임박
  - 🟢 초록: 여유 있음
- 음식 이름으로 검색
- 냉장/냉동/실온 카테고리별 필터링
- 등록된 음식이 없을 때 안내 화면 표시
### 🛒 장바구니
- 사야 할 항목 추가 및 체크 표시
- 스와이프로 식품 / 생활용품 분류 변경 (기본값은 식품)
- 체크된 식품 항목을 유통기한 관리 목록으로 한 번에 옮기기 (옮길 때 유통기한·보관 방법 입력)
- 체크된 항목 일괄 삭제
### 🔔 알림
- 유통기한 하루 전, 오전 9시에 자동 알림 발송
- 항목 삭제 시 예약된 알림도 함께 취소
### 📊 통계
- 전체 보관 중인 음식 개수
- 유통기한 상태별(지남/임박/여유) 막대그래프
- 카테고리별 보유 개수 막대그래프
### ⚙️ 설정
- 라이트 모드 / 다크 모드 / 시스템 설정 따르기 중 선택 가능
### 📱 홈 화면 위젯
- 유통기한 위젯: 임박한 음식 개수와 가장 가까운 항목 표시 (작은/중간 크기)
- 장바구니 위젯: 사야 할 목록을 위젯에서 바로 확인하고 체크 가능
  - 위젯 편집에서 전체 / 식품 / 생활용품 중 표시할 항목 선택 가능
  - 앱을 열지 않고 위젯에서 직접 체크 (App Intents)
  - 항목이 없으면 중앙 정렬된 안내 화면, 있으면 목록형 화면으로 자동 전환
  
### 화면 구성
하단 탭 바로 네 화면을 오갈 수 있습니다.
| 탭 | 설명 |
|---|---|
| 목록 | 등록된 음식 목록, 검색, 카테고리 필터, 추가/수정/삭제, 바코드 스캔 |
| 장바구니 | 사야 할 항목 관리, 체크, 냉장고로 옮기기 |
| 통계 | 유통기한 상태 및 카테고리 별 분포 그래프 |
| 설정 | 화면 모드(라이트/다크) 설정 |

## 기술 스택
- SwiftUI — 전체 UI 구성
- SwiftData — 로컬 데이터 저장 및 관리 (App Group으로 앱·위젯 간 공유)
- WidgetKit / App Intents — 홈 화면 위젯 및 위젯 내 인터랙션
- PhotosUI — 사진 선택 (PhotosPicker)
- AVFoundation — 바코드 스캔 (카메라)
- UserNotifications — 유통기한 임박 알림
- Swift Charts — 통계 화면의 막대그래프
- 공공데이터포털 식품의약품안전처 바코드연계제품정보 API — 바코드로 상품명 조회

## 데이터 모델
- Food
  - name: 음식 이름
  - expiryDate: 유통기한
  - category: 보관 방법 (냉장 / 냉동 / 실온)
  - imageData: 첨부 사진 (선택)

- ShoppingItem
  - name: 항목 이름
  - isChecked: 구매 여부
  - isFood: 식품 여부 (생활용품 구분, 냉장고 이동 대상 판단에 사용)
  - createdAt: 추가된 시각

## 앱 그룹 (App Group)
메인 앱과 위젯이 같은 SwiftData 저장소를 공유하기 위해 App Group을 사용합니다.

- App Group ID: group.com.hanju.foodly
- 앱과 위젯 두 타겟 모두 Signing & Capabilities에서 동일한 App Group이 설정되어 있어야 합니다.
- 데이터가 변경될 때마다 WidgetCenter.shared.reloadTimelines를 호출해 위젯을 갱신합니다.

## 실행 방법
1. Xcode에서 프로젝트 열기
2. 상단에서 시뮬레이터 또는 실제 기기 선택
3. 실행(▶) 버튼 클릭
4. 실제 기기에서 처음 실행할 경우, 기기의 설정 > 일반 > VPN 및 기기 관리에서 개발자 프로필을 신뢰해야 앱이 실행됩니다.

### 실제 기기에서 처음 실행할 경우 아래 절차가 필요함
1. 기기의 설정 > 일반 > 정보에서 iOS 버전을 확인하고, Xcode 프로젝트의 Minimum Deployments를 그 이하로 맞추기
2. 기기의 설정 > 개인정보 보호 및 보안 > 개발자 모드를 켜고 재시작
3. 앱 실행 후, 기기의 설정 > 일반 > VPN 및 기기 관리에서 개발자 프로필 신뢰
